## How to read a status

| Status | Meaning here |
|---|---|
| Not Started | The console calls this controller; the Apple apps call none of its routes. |
| Under Investigation | Neither the console nor the apps call it (staff API kept for other callers, or dead). Needs a decision, not a port. |
| Partially Implemented | The apps call some of the console's routes, or call them through a path built at runtime that has not been hand-checked. |
| Implemented but Unverified | The apps call every route the console calls. **No Apple row can be higher than this today**: since 2026-11-10 both apps compile in CI (`apple.yml`), but no screen has been run on a Mac or iPad. |
| Verified | Reserved for a row whose screen has been built in Xcode, run on the platform and checked against the console page and the Hub's figures. None yet. |
| Blocked | Needs a decision or access before work can start (named in the gaps column). |

macOS and iPadOS share every feature file, so they carry the same status
until a platform-specific defect or check separates them.

  false: `channels/attention`, `channels/context`, `comments/users`,
  `inventory/adjustments/pending`, `reports/international`,
  `reports/collections`.
- **Runtime-built paths confirmed by hand** (the action literal is sent from
  the named file): adjustments approve/reject/reverse
  (`InventoryAdjustments.swift`), transfers approve/cancel/receive
  (`InventoryTransfers.swift`), payroll advances approve/decline/payout/repay
  (`PeoplePayrollView.swift`), purchase returns approve/reject/complete
  (`ProcurementReceipts.swift`, `ApprovalsPanels.swift`), payments
  approve/reject (`ApprovalsPanels.swift`, this branch).
- **Not applicable to native, by design:** `push/subscribe`,
  `push/subscribe-expo`, `push/unsubscribe`, `push/unsubscribe-expo`,
  `push/vapid-public-key` are the browser and retired Expo transports; the
  Apple apps register APNs tokens through `push/subscribe-device`.
- **Blocked on an owner decision:** `database/wipe` (destructive; not ported
  unless the owner asks), `currencies-management/{id}/rates` (FX rates are a
  consequential change under CLAUDE.md §6; port only with approval).
